Track issuance:

  kubectl -n {{ .Release.Namespace }} get certificate
  kubectl -n {{ .Release.Namespace }} describe certificate <name>

Once a certificate shows READY=True, the TLS material is stored in a Secret
of the same name. Mount it into your workloads, for example:

  volumeMounts:
    - name: tls
      mountPath: /certs
      readOnly: true
  volumes:
    - name: tls
      secret:
        secretName: <dash-domain>-tls   # tls.crt + tls.key keys

Switch from staging to production once verified:

  helm upgrade --install {{ .Release.Name }} ./mail-infra/helm/certbot-server \
    --namespace {{ .Release.Namespace }} \
    --reuse-values \
    --set tls.issuer=le-prod

Prerequisites (done once per cluster, NOT by this chart):
  1. Install cert-manager:
       helm install cert-manager oci://quay.io/jetstack/charts/cert-manager \
         --version v1.20.0 --namespace cert-manager --create-namespace \
         --set crds.enabled=true
  2. Bootstrap ClusterIssuers + Cloudflare token:
       bash mail-infra/scripts/cert-manager-bootstrap.sh
