----- 2. Service exposure -----

Type: {{ .Values.service.type }}
{{- if eq .Values.service.type "ClusterIP" }}

  ClusterIP only — reachable from inside the cluster but NOT from the
  public internet. To accept external mail, either:
    a) Switch service.type to LoadBalancer (if your cloud provides L4 LB), OR
    b) Front this ClusterIP with an external TCP load balancer / firewall NAT.

{{- else if eq .Values.service.type "LoadBalancer" }}

  Watch the LoadBalancer get its address:
    kubectl -n {{ .Release.Namespace }} get svc {{ include "silver-smtp.fullname" . }} -w

  Then publish DNS:
    MX  {{ .Values.domain }}.  10  {{ include "silver-smtp.hostname" . }}.
    A   {{ include "silver-smtp.hostname" . }}.   <load-balancer-ip>
{{- end }}
